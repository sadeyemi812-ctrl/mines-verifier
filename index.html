💎 Mines Fairness Verifier

Checks a finished Stake Mines game. Rotate your seed pair first, then paste the revealed (unhashed) server seed here. This can't predict games, because the server seed stays secret until you rotate it.

How this was calculated

1. Bytes = HMAC-SHA256(key = server seed, message = "clientSeed:nonce:round"), with round = 0, 1, 2… until there are enough bytes.

2. Each 4 bytes become a float in [0, 1): b0/256 + b1/256² + b2/256³ + b3/256⁴.

3. Tiles 0–24 are shuffled: for float i, pick index ⌊float × (25 − i)⌋ from the tiles left. The first N picks are the mines.

Tiles are numbered row by row from the top-left (0 = top-left, 4 = top-right, 24 = bottom-right).
